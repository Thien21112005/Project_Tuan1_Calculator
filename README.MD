# 🧮 Calculator Android App

## 📱 Giới thiệu

Calculator là ứng dụng máy tính hiện đại cho Android với giao diện gradient đẹp mắt.

## ✨ Tính năng

### 🔢 Chế độ dọc (Portrait)
- ✅ Phép tính cơ bản: `+` `-` `×` `÷`
- ✅ Phần trăm `%`
- ✅ Đổi dấu `+/-`
- ✅ Xóa `C` và Delete `⌫`

### 🔬 Chế độ ngang (Landscape)
- ✅ Hàm lượng giác: `sin` `cos` `tan`
- ✅ Logarithm: `log` `ln`
- ✅ Hàm toán: `x²` `√`
- ✅ Hằng số: `π` `e`
- ✅ Giai thừa: `n!`

### 📜 Lịch sử
- ✅ Lưu vào JSON
- ✅ Xem lại calculations
- ✅ Delete từng phép tính

## 🛠️ Tech Stack

- **Language**: Java
- **Min SDK**: API 24 (Android 7.0)
- **Target SDK**: API 34 (Android 14)
- **UI**: Material Design 3

## 📥 Cài đặt
```bash
# Clone repository
git clone https://github.com/yourusername/calculator-android.git

# Mở trong Android Studio
File → Open → Chọn folder

# Run
Shift + F10
```
